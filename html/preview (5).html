PRODUCTION ENGINE BLUEPRINT

How the backend should actually work

1 · Data reliability gatePrices, corporate actions, financials, filings, transcripts, news, macro, commodities, supply-chain and ownership data are normalized, timestamped, deduplicated and quality-scored before modeling.
2 · Feature storeBuild point-in-time features only: profitability, balance-sheet, cash conversion, estimate revisions, transcript themes, event windows, volatility, liquidity, macro betas and graph relations.
3 · Multi-model layerRobust z-scores + factor models + rolling/DCC correlation + regime model + causal time-series discovery + embeddings + heterogeneous graph learning. No single model gets final authority.
4 · Evidence fusionSignals are calibrated by recency, source quality, cross-model agreement and out-of-sample reliability. Low-confidence relationships appear as hypotheses, never facts.
5 · DNA engineCreate a dynamic vector from structural fundamentals, management behavior, market response and event recovery. Similarity uses weighted distance per regime, not one static percentage.
6 · Dependency engineBuild a temporal heterogeneous graph: holding↔factor, holding↔holding, supplier↔customer, theme↔company, macro↔sector. Store lag, sign, strength, regime and confidence on every edge.
7 · Counterfactual simulatorShock factors and propagate effects only through calibrated edges. Return ranges + confidence intervals rather than false-precision price targets.
8 · Voice orchestrationSpeech→intent/entity parser→analytics tools→evidence retrieval→structured result→UI action + spoken explanation. Voice can change tickers, factors, scenarios and drilldowns.
